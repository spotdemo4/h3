# H3 Webtransport

Implementation of Webtransport protocol as extension of the h3 crate

This is `h3-webtransport` from the [spotdemo4/h3](https://github.com/spotdemo4/h3) fork, published as `trev-h3-webtransport` for use with [`trev-h3`](https://crates.io/crates/trev-h3). The library is still named `h3_webtransport`. See the [fork's README](https://github.com/spotdemo4/h3#readme) for what it changes, such as WebTransport draft negotiation and closing sessions.

# Status
This crate is still in experimental. The API is subject to change. It may contain bugs and is not yet complete. Use with caution.
